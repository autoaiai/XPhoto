## 这是什么

XPhoto 是为「一天要交几十张片」的商业人像流程做的：修一张证件照、一组形象照，不用在
Photoshop、磨皮插件、抠图网站、寸照排版工具之间来回倒文件。

- **一个窗口走完全流程**：导入 → 修脸修身 → 调色裁剪 → 寸照排版 → 导出。
- **本地推理，不上传**：人脸检测、人体分割、抠像、消除、降噪全部在本机跑，没有把照片发出去的入口。
- **改一处只算一处**：画布按脏矩形增量重绘，拖滑杆、刷蒙版几十毫秒出画面，不用等整张 6000×8000 重算。
- **出片级细节**：寸照按 300dpi 出图，导出在原图分辨率上重算，不是屏幕截图放大。

### 三步上手

1. 左侧「图库」页或顶部「打开图片」载入照片；没有素材也能先用内置示例。
2. 左栏竖排选功能：美颜 / 美体 / 预设 / 调色 / 裁剪 / 寸照 / AI 修图，右栏拖滑杆，画面实时反馈。
3. 顶部「导出」存 PNG 或 JPEG。想一键出片，用「一键精修」按人脸实测结果自动推参数。

## 为什么用它

- **全程离线。** 人脸检测、人体分割、抠像、消除、降噪都在本地推理，原图不上传；
  软件里没有任何把照片发往外部服务的入口。
- **磨皮不是模糊。** 中性灰分层 + 归一化卷积，只压平坦皮肤上的色块，毛孔、睫毛、唇线这些真结构留着。
- **蒙版是真的蒙版。** 修脸只动脸、修身体只动身体、换背景保留发丝；
  模型分不出的裸皮（胸口、锁骨）可以用画笔手绘补进去，加法减法都行。
- **只作用在人身上。** 美体靠人体分割 + 关键点约束，背景不跟着一起拉伸；全身美白按肤色门控并排除衣服分类，
  不会把白衬衫和金缎一起提亮。
- **不糊弄你。** 没有检测到人脸时如实提示「当前是按画面比例居中的框，不满足证件照构图」；
  相机取景读不到的参数就标注读不到；已知的缺陷写在文档里，不粉饰。

## 功能一览

### 图库与导入

- 单张 / 多选 / 整个文件夹导入，缩略图胶片条，RAW 与 HEIC 带角标。
- 舞台左上角显示 EXIF：机身、镜头、焦距、光圈、快门、ISO、尺寸、曝光补偿。
- 联机拍摄：相机检测、热文件夹自动导入（文件写入稳定后才读，不会读到半张）、USB 实时取景抓帧。

### 美颜

八组参数、上百个滑杆，全部只作用在检测到的人脸皮肤上：

| 组 | 内容 |
| --- | --- |
| 肤色 | 磨皮、质感保留、美白、匀肤、丰盈、清透、去油、去皱、黑眼圈、锐化、边缘锐化 |
| 脸型 | 瘦脸、小头（含头发）、窄脸、下颌线、颧骨、短脸、V 脸、下巴、三庭、发际线 |
| 五官 | 眼睛（大小/亮眼/眼距/眼角/眼高/眼斜）、鼻子（鼻梁/鼻翼/鼻头）、嘴（笑容/唇厚/嘴角）、眉（眉高/眉斜） |
| 妆容 | 唇色、腮红、修容、卧蚕、睫毛、眼线、眼影、色彩浓度、高光、雀斑 |

- **50 款妆容预设**（微醺、氧气感、甜心芭比、中国妆、古早韩妆、纯欲蝴蝶兰、白开水、芭蕾少女……）
  与 **7 款脸型预设**（粉芭比、韩系清透、蜜桃初恋、冻龄、柔光、空气感、少女光）。
- **全身肤色**单独一层：美白覆盖到脸以外的皮肤（手臂、颈、腿），按肤色门控 + 衣服分类排除。
- **多人脸**：可全部一起调、只调某一张、或给每张脸独立开关；缩略图按当前照片实时渲染。
- **皮肤蒙版画笔**：胸、锁骨这类模型没有「躯干皮肤」类的区域，刷两笔补进去即可参与美白/磨皮，
  也能反擦排除。

### 美体

智能美体（人体分割 + 身体关键点约束）与手动美体两组：瘦身、腰线、腿长、腿细、天鹅颈、
手臂、肩宽、头肩比、丰胸、拉伸、全身磨皮与美白。**只作用人体，背景不跟着拉伸**。

### 预设

- 调色预置 13 款：质感肌、奶油肌、原生肌、冷白、胶片富士、徕卡 M9、哈苏蓝、暖阳、蓝冰、
  黑白、墨影、电影感、清新。
- 自己保存的成套参数，带强度滑杆，可一键套用到全部人脸。

### 调色

基础（曝光、对比、高光、阴影、白、黑、色温、色调、自然饱和度、饱和度、清晰度、去朦胧、
纹理、暗角、颗粒）、HSL 混色、曲线、风格化、白平衡（原照 / 自动 / 日光 / 阴天 / 阴影 /
白炽灯 / 荧光灯 / 闪光灯）。

### 裁剪

比例档（原图、1:1、3:4、2:3、4:5、9:16、自由）+ 手动裁剪框：拖框体移动、拖四角改大小，
编辑时看整图，点「完成」后按框铺满。

### 寸照

- **12 档标准尺寸**：一寸、大一寸、小一寸、二寸、小二寸、大二寸、护照、身份证、美签、驾照、
  社保、结婚证。点一下自动按人脸放好裁剪框（头顶留白、发顶到下巴占比、人脸居中）。
- **8 种背景**：不换背景、白、浅蓝、蓝、深蓝、红、灰、自定义色。换背景走主体蒙版，发丝边缘保留。
- **排版打印**：5 / 6 / 7 寸与 A4，300dpi 自动排满并带裁切线。

### 局部工具（左栏底部）

| 工具 | 能力 |
| --- | --- |
| 液化 | PS 式四种：向前变形、褶皱、膨胀、旋转；冻结/解冻蒙版、画笔大小/强度/半径/羽化 |
| 污点修复 | 涂抹即补，基于周边纹理 |
| 智能消除 | 框选或涂抹要移除的物体，模型补全背景 |
| AI 点修 | 比污点修复更大的采样范围、更稳的过渡，适合成片色斑、油光、细碎杂物 |
| 祛边 | 两种模式：抠像白边、镜头色边 |
| 参考线 | 三分、中心、黄金、网格，也可自绘并拖动 |
| 人脸节点 | 控制点式调脸，PS 那套手感 |

画笔快捷键：`[` / `]` 调大小，`Shift + [` / `Shift + ]` 调羽化。

### AI 修图

四个页签，模型缺哪个就在原地给下载按钮：

- **抠图** —— 人像抠图，出透明 PNG；发丝级（RVM）与精细（BiRefNet-lite fp16）两条通道。
- **消除** —— 在照片上拖一个矩形框选物体，模型补全（LaMa）；`Esc` 取消框选。
- **分割降噪** —— 人像分割后可整幅降噪或只降皮肤，去噪点与压缩痕迹。
- **模型** —— 查看已装 / 缺失，单个或全部下载；目录永远是可写位置（`%APPDATA%\portrait-lab\models`），
  不会往只读的安装目录写。

GPU 优先走 DirectML，探测或验证失败会自动回落 CPU，界面会写明当前在哪个后端。
若检测到上次崩在推理库，会先停用 AI 功能并提示，避免反复崩。

### 联机拍摄

- **相机检测**：枚举已连接的 Windows 成像设备。
- **热文件夹**：选一个目录开始监视，相机厂商工具或 Wi-Fi 落进来的新照片自动进胶片条。
- **USB 实时取景**：走系统 UVC 取景，圆形按钮抓帧导入。这是摄像头级取景，读不到相机参数、
  不能遥控快门与对焦——界面照实标注。

### 一键精修

按人脸实测结果推参数，不是一张写死的表：检测 → 光影 → 修复 → 塑形 → 调色，五步可看进度，
可对全部人脸或当前人脸套用。

### 导出

PNG 无损或 JPEG，编码格式跟随你选的后缀（选 `.jpg` 就真的是 JPEG）。
导出在原图分辨率上重算，液化、污点修复、消除、蒙版都在导出图里。

## 支持的文件格式

| 类型 | 后缀 | 解码方式 |
| --- | --- | --- |
| 相机 RAW（29 种） | `CR2 CR3 CRW NEF NRW ARW SRF SR2 DNG RAF ORF RW2 PEF SRW RAW RWL DCR KDC MRW X3F 3FR FFF IIQ MOS ERF MEF RWZ GPR BRAW` | 抽取 RAW 内嵌预览 + 补写方向标记 |
| HEIC / HEIF | `HEIC HEIF HIF` | libheif（WebAssembly）本地解码 |
| 常规位图 | `JPG JPEG JPE JFIF PNG WEBP BMP GIF TIF TIFF AVIF` | Chromium 原生解码 |

三类文件都按 EXIF 方向自动旋正；RAW 不重新编码，零画质损失。
超大图自动降采样显示，导出仍按原图处理。

> **RAW 的边界**：完整显影（去马赛克 + 白平衡 + 色彩矩阵）需要 LibRaw 这类原生库，
> 当前走「内嵌预览」路线，界面上会标「内嵌预览」。多数相机的内嵌预览本身就是传感器输出尺寸，
> 所以导出分辨率通常不受影响。

## 更新

参考 AICUT 的检查节奏，但**安装时机按修图软件改过**：不倒计时自动装，退出时也不偷偷装。

- 启动 15 秒后自动检查一次，之后每 6 小时复查；电脑休眠唤醒后 15 秒再查；
  网络失败 5 分钟一拍重试，不会因一次断网拖 6 小时。
- 查到新版本 → **后台静默下载**到本地缓存，不弹窗、不倒计时、不打断正在修的图；
  下载走换源 + 断点续传，并做三重校验（文件大小、PE 头、sha256）。
- 下载完什么都不提示，只在 `<用户数据目录>\updates\pending.json` 记一笔。
- **下次启动软件时**才自动静默安装并重新打开。那一刻还没打开任何照片，
  天然不会丢未导出的修改；正常退出软件不会安装。
- 想立刻装也行：「帮助 → 软件更新」手动检查，弹窗里点「立即安装并更新」，装完自动重开。
- 状态写在 `<用户数据目录>\logs\updates.log`（只有状态与版本号，不记地址）；
  缓存里的旧安装包自动留最近 2 个，其余清理。

## 常见问题

**打开软件提示 AI 功能被停用？**
上一次运行崩在推理库时会主动熔断，避免连环崩。确认能正常打开照片后，在「AI 修图 → 模型」
里刷新即可恢复；也可以用 `--force-ai` 启动清掉记录。

**AI 功能点不动 / 模型缺失？**
「AI 修图 → 模型」会逐行列出缺哪个文件并给下载按钮，下载落在
`%APPDATA%\portrait-lab\models`（可用 `PORTRAIT_MODELS_DIR` 指定自定义盘位）。

**导出尺寸和预期不一样？**
导出始终按载入的原图分辨率重算，跟屏幕缩放无关。两种情况会变小：载入的是 RAW 内嵌预览
（上限就是那张预览的尺寸），或者原图带 EXIF 方向、出图按旋正后的画幅算。

**拖滑杆时画面糊了一瞬？**
拖动期自动降档预览保流畅，停手 400ms 后重算到全分辨率，静止时会再算一次完整版。

**多人合影只想修一个人？**
右栏「多人脸」切成「单独调某一人脸」，或直接关掉某张脸右上角的开关。
注意全身肤色是整幅统一处理，仍会覆盖到关掉的脸——否则那张脸上会留一块色差。

- 程序自带 VC++ 运行库，不再受系统运行库版本混装影响——这是「打开图片就崩溃」的真根因。
- 崩溃兜底与取证：异常退出记录日志与转储，检测到上次崩在推理库时自动停用 AI。
- 崩溃提示写出实际检测到的运行库版本与修复办法，而不是一句「出错了」。
- 修复更新检查读错文件名、收不到新版本提示。

更早版本见 [Releases](https://github.com/autoaiai/XPhoto/releases)。

## 开发

技术栈：Electron + TypeScript（主进程 / preload / renderer 三层，`contextIsolation` 开启）；
图像算法在 `beauty.js` / `skin.js` / `liquify.js` / `body.js`；
AI 推理走 `onnxruntime-node`（分割、抠像、消除、降噪）与 MediaPipe（人体分割与关键点）；
人脸检测与 68 点关键点由 face-api.js 随包离线提供。

```bash
npm install
npm start          # 编译并启动
npm run dist       # 只出 NSIS 安装包
npm test           # 全量回归（数百项像素级断言，含 i18n / 打包 / 崩溃兜底）
```
